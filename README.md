# 掌鑑（てのひらかがみ）

手のひらを撮って、四大線（生命線・頭脳線・感情線・運命線）を指でなぞるだけの手相占い。
性格・仕事・恋愛・健康の 4 分野を読み解いて、結果は画像で保存できます。

```bash
pnpm install
pnpm dev      # http://localhost:5360
pnpm test     # Vitest
pnpm build
```

## 仕組み

```
撮影 ──▶ 掌座標系をつくる ──▶ 4本をなぞる ──▶ 特徴量 ──▶ 判定 ──▶ 解釈 ──▶ 文章化
        (MediaPipe or 手動)                   純粋関数だけで確定          WebLLM
```

### 1. 掌座標系（`src/lib/palmFrame.js`）

写真は撮るたびに距離も角度も変わるので、画素座標のままでは「線が長い / 短い」が
撮り方で変わってしまいます。そこで **手そのものを基準にした座標系** に移します。

- 原点 = 手首の中央
- y 軸 = 手首 → 指の付け根（**1.0 = 指の付け根のライン**）
- x 軸 = 小指側 → 親指側（**正 = 親指側**）

x 軸を「小指側→親指側」で定義しているので、左手でも右手でも、写真が鏡像でも、
判定ルールをそのまま使い回せます。基準点の 3 か所は MediaPipe HandLandmarker が
自動で取り、取れなければユーザーがタップして指定します。

### 2. 判定は純粋関数だけで確定（`src/lib/rules.js`）

なぞった線 → 特徴量（長さ・曲がり・始点/終点・切れ目）→ 判定コード → 解釈。
**同じ手相なら必ず同じ結果**になります。しきい値は `THRESHOLDS` に集約。

### 3. 文章化だけを WebLLM に任せる（`src/llm/`）

ブラウザ内の WebLLM（WebGPU）は「確定済みの鑑定メモを占い師の口調に書き直す」役だけを
担当し、手相の解釈そのものには関与しません。WebGPU が無い環境では定型文にフォールバックします。

## 構成

| パス | 役割 |
| --- | --- |
| `src/lib/geometry.js` | ポリラインの長さ・曲率・間引き |
| `src/lib/palmFrame.js` | 掌座標系 |
| `src/lib/features.js` | なぞった線 → 特徴量（描く向き・ストローク分割の正規化） |
| `src/lib/rules.js` | 特徴量 → 判定コード（しきい値はここ） |
| `src/lib/data/interpretations.js` | 判定コード → 解釈文・点数 |
| `src/lib/reading.js` | 判定 → 構造化リーディング＋定型文 |
| `src/lib/prompt.js` | WebLLM のプロンプト組み立てと寛容なパース |
| `src/lib/history.js` | localStorage の鑑定履歴 |
| `src/ui/` | カメラ・キャンバス・共有カード |
| `src/app.js` | 画面遷移の配線 |

## デバッグ

`window.__app` から触れます。

```js
__app.runSample()                     // サンプルの手相で結果まで一気に見る
__app.usePhoto(__app.samplePhoto())   // 撮影済みの状態から始める
__app.stage.pushTap({x, y})           // 基準点をコードから置く
__app.stage.pushStroke(points)        // 線をコードからなぞる（画像の画素座標）
__app.reading                         // 直近の鑑定結果
```

## 注記

手相占いはエンターテインメントです。生命線の長さは寿命ではなく生命力の強さを見るもの、
という現代の一般的な読み方に揃えています。健康や進路の判断は専門家へ。
